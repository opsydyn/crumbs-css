# M11.1 Typed Local Variables Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. For this session preserve the user's native/inline execution preference and use superpowers:executing-plans after plan review.

**Goal:** Add typed standalone variables and immutable instance assignment, retaining native property semantics and qualifying the distributed API in Expo consumers.

**Architecture:** Authoring creates versioned immutable local-variable/fallback data; native capture emits local style plans instead of sending unresolved values through CSS or React Native. An opt-in runtime admits assignment snapshots, resolves effective declarations and reuses unchanged outputs. A small shared theme-context module connects the new hook to existing providers without putting local resolution into existing runtime graphs.

**Tech Stack:** TypeScript with strict/exact optional types, Bun tests, fast-check, the existing React 19 / React Native 0.85.3 / Expo 56 stack, and pinned Effect `4.0.0-rc.115` at compiler/schema boundaries.

**Spec:** [Approved M11.1 design](../specs/2026-10-08-m11-1-local-vars-design.md), approved as written on 2026-10-08 after commit `1825e9e`.

**Status:** Proposed implementation plan; human review pending. No implementation or native qualification is claimed.

**Delivery:** One M11.1 implementation slice and one final implementation commit. Tasks below are internal checkpoints, not additional roadmap slices. This documentation/plan commit is separate. Preserve native/inline execution; review this plan before implementation.

## Global Constraints

- Authoring: `createVar`, `fallbackVar` in `@opsydyn/crumbs-css/style`; runtime: `assignVars`, `resolveAssignedStyles`, `useAssignedStyles` in `@opsydyn/crumbs-css/theme/vars`.
- `createVar(domain, identity)` requires `TokenDomainDefinition` and explicit `{ owner, name, version }`; reuse the existing package/name/positive-safe-integer grammar and domain semantics.
- New tags are `crumbs.css.local-var`, `crumbs.css.local-fallback`, `crumbs.css.local-assignments` and `crumbs.css.local-style-plan`, each version `1`.
- A fallback has at most **16 local handles** and one literal or public typed same-domain theme terminal. **Only absence** selects the next branch; invalid data remains an error.
- Assignments fully populate the supplied nested shape; subsets use subset shapes. `assignVars({}, {})` replaces the prior snapshot with the canonical empty snapshot.
- Follow the existing **64-container** plain-data depth limit; reject accessors without execution, cycles, symbols, extra fields, unsupported prototypes and decorated/sparse descriptor arrays.
- Literal duplicate equality uses `Object.is`, including the distinction between `0` and `-0`. No mutation or implicit inherited assignments.
- Preserve view/text/image types, native shorthand/last-write composition, existing theme diagnostics, existing exports and the meaning/version of every existing payload.
- Local operands are primitive scalar properties only. No local operands in recipes, Sprinkles, conditions, expressions or structured native values; existing supported static structured values still compose normally.
- Use existing theme context/store, unconditional Hooks and weak identity caches for fully admitted immutable inputs. Mutable unknown data is copied and revalidated; its original identity cannot be trusted as a cache key.
- Keep Effect, compiler/authoring machinery and CSS parsers out of the new ordinary runtime graph. Keep the current Effect pin and add no product or animation dependency.
- Qualify packed consumer imports/types, iOS Simulator and Android emulator interactions and relevant costs. Physical devices and spoken-reader acceptance remain deferred.
- Preserve active M10.5 policy, numerical registry/baselines and its unresolved warm-transform blocker. No release bypass, push, tag or publication belongs to M11.1.

## Review Focus

1. Clearing one instance's complete snapshot must restore its default without keeping an old assignment or affecting a sibling (Tasks 3–5).
2. An unused valid theme terminal must not require a provider, while an invalid descriptor or invalid assignment must not be hidden by a populated local branch (Tasks 1, 3–4).
3. A mutable decoded object changed after its first use must be re-admitted; a stale cache must not hide changed values or invalid versions (Tasks 1, 3).
4. A composed shorthand, a shadowed required variable and existing static transform/shadow values must preserve the native winning declaration and primitive type (Task 2).
5. Providers and Hooks imported through different focused/compatibility entries, in either order and either module format, must share one theme store and clean up subscriptions (Task 4).
