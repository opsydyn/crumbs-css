## Review Focus

1. A predeclared config union or any/index-signature module witness can bypass naive literal inference: fail the actual authoring call, retaining valid component props and optional args (Task 1).
2. A descriptor can carry a late getter, huge expanded native style or local operand under an innocuous record: reject before emission without running the getter or freezing caller/shared data (Tasks 1–2).
3. Two aliases can accidentally construct two components, while identical separate factory invocations get wrongly interned: module-local identity must preserve both distinctions across nested exports (Tasks 2–4).
4. Runtime package conditions/re-exports or a retargeted self-reference can point to a missing/different named factory: verify actual static linkage and current receipts, and prove the native module was never evaluated by compilation (Tasks 3–5).
5. A literal wrapper can secretly require a provider, or a themed wrapper can remount on unrelated updates: independent native controls and lifetime/real preference checks must distinguish styling, theme and component identity (Task 6).
