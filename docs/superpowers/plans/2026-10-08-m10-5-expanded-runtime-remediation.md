**Goal:** Qualify one complete API-preserving runtime/compiler candidate against all 21 host rows, conditionally admitting four expanded-runtime byte baselines under the approved zero-growth policy.

## Review Focus

1. Built functions: preserved export names can conceal altered method name/arity/constructibility or property descriptors; inspect actual built callable values (Tasks 1–2).
2. Chunk evaluation: helper fusion can duplicate focused bindings, change side-effect order or introduce cycles even when values match (Tasks 1–2).
3. Resolution alternatives: installed-file edits, a newly nearer package, symlink retarget or persisted malformed receipt must invalidate both memo and outer Metro cache (Tasks 3 and 6).
4. Admission laundering: stable sizes with different hashes, fifteen scans of one build, or `B+1` under the cap must fail; seventeen unchanged contracts must remain exact (Task 4).
5. Handoff replay: mixed policy/registry/report/manifest identities or an edited baseline must reject even when all displayed rows say pass (Tasks 5–6).
