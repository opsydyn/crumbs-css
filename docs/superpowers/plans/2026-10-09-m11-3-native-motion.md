## Global Constraints

- `/theme/motion` exports only `defineMotion`; its graph contains no React, React Native JS, Effect, Node or compiler. `/theme/motion/native` exports only `useNativeMotion`; its runtime externals are public React/React Native only. No new values through existing entries or aliases.
- Pure public types: NativeMotionChannel, NativeMotionTarget, NativeMotionDefinitionInput, NativeMotionDefinition, NativeMotionState, NativeMotionEasing. Native types: NativeMotionOptions, NativeMotionController, NativeMotionRun, NativeMotionResult; pure types may be re-exported there.
- Input exactly states/transition; output tag `crumbs.css.motion-definition`, formatVersion 1, states/transition, with a type-only nominal marker. All output data is copied/frozen; no caller mutation/freeze. Native admission requires completely frozen structurally valid definitions, including foreign same-format package copies.
- 1–16 states; names match `[A-Za-z][A-Za-z0-9._-]*`, at most 64 characters; exclude __proto__, prototype, constructor. Each state has the same exact nonempty 1–6 channel set. Only opacity/translateX/translateY/scale/scaleX/scaleY; reject unsupported keys on predeclared inputs as well as fresh literals.
- Own enumerable data descriptors only; plain/null prototypes; reject accessor/symbol/hidden/inherited/extra fields and malformed arrays without getter execution. No functions or token objects as numeric data. Unsupported format fails explicitly.
- Opacity finite in [0,1]; transforms finite signed numbers with finite float32 conversion, preserving authored precision. -0 becomes +0. Translation uses native layout units; scales unitless. Fixed transform order: translateX, translateY, scale, scaleX, scaleY. Returned transform replaces the entire field; use a wrapper for static transforms.
- Timing only; duration finite milliseconds in [0,60000], including fractions. Easing linear/ease-in/ease-out/ease-in-out maps to linear/quadratic-in/quadratic-out/quadratic-in-out. General duration token semantics remain unchanged.
- Hook options exactly initial/motion/optional duration; motion is required full/reduced. Initial seeds a definition-reference owner once. A new definition reference makes a new owner; changing initial alone does not reset. Commit options only in layout setup, never speculative render.
- Controller only style/animateTo/set/cancel. Run only result/cancel. Results resolve once, never reject: finished {target,mode:animated|immediate}; cancelled {target,reason:cancelled|superseded|set|deactivated|driver-stopped}; failed {target,code:CRUMBS_CSS_MOTION_DRIVER_FAILED}.
- Repeat active target returns the same run. A reached target finishes immediately. Cancelled presentation is not a reached target. Late run/activation/read callbacks cannot act on current work. No run history, public queue, callbacks, per-frame listener, polling or timeout-generated success.
- Native driver on iOS/Android, JS driver only for web smoke, fixed per owner; other platforms rejected. isInteraction=false. Read current stopped presentation via public stopAnimation(callback), not private JS snapshots. At most six values/timing objects, one current run/read cohort; coalesce targets within a pending cohort.
- Reduced motion during preparation/running stops and reaches the latest target immediately; returning full does not replay it. Zero duration makes no timed/read work. Driver failures produce failed; best-effort cleanup covers every channel; Hook cleanup never throws. Imperative set driver failures throw the bounded diagnostic and claim no native rollback.
- Strict Mode and committed Suspense deactivate/reactivate epochs; no retired run is revived. Commands before activation error; inactive valid animateTo resolves cancelled/deactivated, set/cancel no-op. Invalid input never stops a valid run.
- One existing React peer; no shared provider/global registry or public adapter registration. No .css.ts motion capture, compiler payload/version changes, spring/gesture/layout/colour/serialization subsystem, product dependency or lock change.
- Actual installed iOS Simulator and Android emulator interactions plus Expo iOS/Android/web exports are required. Physical/spoken-reader work stays deferred. Synthetic renderer/fake-driver proof and development Hermes acceptance are distinct from release/device performance.
- Keep M10.5 numerical registry, policy, both retained failures and release prerequisites unchanged. Record any new blocking result; do not silently reuse M11.2's feature deferral. No repeated collection to chase timing, push, publication or M11.4 implementation.

## Review Focus

1. A stale native sample can arrive after cancel/set/reduced-motion/replacement and must neither write nodes nor resolve a newer run (Tasks 2–3).
2. A native stop/start callback can run synchronously or one channel can fail after others succeed; the owner must retire authority first and never report partial success (Tasks 2–3).
3. An aborted render or three committed Suspense hide/reveal cycles can retain controllers/options; only committed options and fresh activation epochs may drive nodes (Task 3).
4. A predeclared target map can bypass excess-property inference, or an options argument can widen state names; installed types and runtime admission must both reject it (Tasks 1, 3).
5. Host mocks or the new native allowance can accidentally leak into old entries or the actual Expo app; native maps must show real installed peers and old graph denials must still fail (Tasks 3–5).
