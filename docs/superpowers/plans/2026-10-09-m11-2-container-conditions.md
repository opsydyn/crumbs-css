## Global Constraints

- New opt-in entry: `@opsydyn/crumbs-css/theme/containers`; value exports exactly `defineContainer`, `getContainerBucket`, `resolveContainerValue`, `useContainerLayout`, `ContainerProvider`, `useContainerValue`.
- Public types exactly `NativeContainerAxis`, `NativeContainerDefinitionInput`, `NativeContainerDefinition`, `NativeContainerBucket`, `NativeContainerValues`, `NativeContainerLayout`, `ContainerProviderProps`.
- Exact definition input fields: owner/name/version/axis/buckets. Reuse existing identity grammar; axis is width or height; 1–16 own enumerable bucket entries, names at most 64 characters, distinct finite non-negative minima and exactly one zero. Lower bounds are inclusive; fractional sizes are unrounded; -0 normalises to +0.
- Definition tag `crumbs.css.container-definition`, formatVersion 1; separate positive-safe-integer compatibility identity.version. Reserve unmeasured, __proto__, prototype and constructor. Reject getters without execution, symbol/extra/non-enumerable fields, sparse/decorated payload arrays and unsupported prototypes/versions.
- No size means unmeasured; zero is a genuine measurement. Every value map contains every bucket and unmeasured. Present undefined/null/false is a value; invalid data is an error.
- Owner-local key `Symbol.for('crumbs.css.container-owner.v1')`; one versioned shared React context; no process-wide owner/definition registry. Identity and shape must match across package copies under one React installation.
- One handle measures one native View and has one committed provider. Query the nearest requested identity, including unmeasured inner owners; no window/ancestor bootstrap. Portal lookup follows React context.
- At most 17 owner snapshots; no raw dimensions/history in snapshots or cache keys. Same-bucket events publish nothing; selector equality is Object.is. Current table/selection only, with subscriptions removed on final unsubscribe/replacement/unmount.
- Late retired callbacks are no-ops before payload reads. Strict Mode cleanup/setup replay preserves the live measured bucket and can resubscribe. A keyed remount resets to unmeasured.
- Native queried axes are independently constrained. No hidden rounding, debounce, hysteresis, polling or frame listener; reject reentrant different-bucket publication. Sequential oscillation is a bounded test negative control, not automatically repaired by the library.
- Ordinary definitions live in .ts modules; no compiler capture, theme/window condition axis, descriptor-version migration or changes to recipe/Sprinkles/expression APIs. Container selection returns supplied values without resolving them.
- New JavaScript entry builds independently; canonical declaration graph remains shared. Its externals are React only; no React Native JS, Node, Effect, compiler, CSS parser or esbuild reachability. Existing entry exports, binding relationships and build groups remain intact.
- No product dependency/stack upgrade. DOM hydration adds jsdom 26.1.0 only to the owned test consumer's generated devDependencies/lock, never to root or published-package manifests.
- Packed iOS/Android/web exports and iOS Simulator/Android emulator interactions are required. Physical-device and screen-reader acceptance stays deferred. Development Hermes functional evidence does not establish release-mode/device performance.
- Preserve active M10.5 policy, numerical registry/baselines, the existing warm-transform blocker and matching Expo/Metro requirement. No threshold changes, push, tag, publication or M11.3 implementation.

## Review Focus

1. Reusing the same mutable value-table object after changing a branch must refresh selection on the next render, without admitting getters or retaining an old branch (Tasks 1, 3).
2. A changed definition identity/signature must reset ownership; equivalent reordered definitions must preserve it; callbacks retained from the old owner cannot update the new one (Tasks 2, 3).
3. Nested or portal consumers must read the intended React owner even before measurement; same-named outer size cannot mask an unmeasured or incompatible inner owner (Tasks 3, 5).
4. A never-committed/suspended render, Strict Mode effect replay and duplicate provider claims must not leak subscriptions, poison a live handle or claim a device measurement (Tasks 2, 3).
5. ESM/CJS and two installed package copies must exchange handles through the internal protocol under one React; a forged/incompatible global registry slot must fail before its getters or methods run (Tasks 2, 3, 5).

**Interfaces:**

- The closed owner-local facade has formatVersion **1**, admitted definition, key, signature and these methods: `getSnapshot(): ContainerSnapshot`, `getServerSnapshot(): ContainerSnapshot`, `subscribe(listener: () => void): () => void`, `updateSize(size: unknown): boolean`, `onLayout(event: LayoutChangeEvent): void`, `activate(): void`, `deactivate(): void`, `claimProvider(token: object): () => void`, `inspect(): ContainerOwnerStats`. `ContainerOwnerStats` has phase `'created'|'active'|'inactive'` and numeric listeners/providerClaims/internedSnapshots/publications; inspect is not exported publicly or a telemetry facility.

Created owners accept initial-commit events before subscription; inactive owners ignore them before payload reads. activate resumes a live Strict Mode owner with its existing bucket. deactivate removes owner listeners/claims and disables events; release/unsubscribe remain idempotent, and a later setup can claim/subscribe afresh. Capture a monotonically increasing claim generation with each token so an old release cannot clear a newer claim, including when Strict Mode reuses the same provider token. Replay removes old selector subscriptions before attaching fresh ones; activation never revives old listener registrations.

It selects only from the current owner/table, attaches one parent subscription for its first listener and detaches on the last. The server value is always table.unmeasured. Empty selectors can resubscribe; React cleanup does not permanently dispose them.
