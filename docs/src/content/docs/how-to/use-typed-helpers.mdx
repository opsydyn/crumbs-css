---
title: Use typed helpers
description: Apply viewStyle, textStyle, and imageStyle when a style targets one React Native primitive.
---

Use the narrowest helper when the style is intended for a single primitive:

- `viewStyle`
- `textStyle`
- `imageStyle`

## Example

```ts
import { imageStyle, textStyle, viewStyle } from "@opsydyn/crumbs-css/style"

export const panel = viewStyle({
  padding: 24,
})

export const title = textStyle({
  fontSize: 18,
  fontWeight: "700",
})

export const crest = imageStyle({
  height: 48,
  resizeMode: "cover",
  width: 48,
})
```

## Compose native styles

```ts
const copy = textStyle({ color: "black", fontSize: 16 })
export const heading = textStyle([copy, [{ fontSize: 24, fontWeight: "700" }]])
```

Later authored entries override the same native property. Crumbs helpers accept multiple bases, repeated bases and nested readonly arrays, with the same primitive inline property checks. `styleVariants` also accepts composed values. Use the Crumbs authoring entrypoint for this ordered native contract; direct vanilla-extract composition retains upstream class-list processing.

Literal padding shorthand/longhand ordering is covered. Token-backed shorthand normalization remains incomplete and is a separate correctness repair.

## Why use them

They improve type safety for native styles:

- obvious cross-kind props fail earlier
- theme tokens remain supported
- intent is clearer to readers and tooling

## When not to use them

Use `style` when a single export intentionally mixes properties across style kinds or you want a generic native style surface.
