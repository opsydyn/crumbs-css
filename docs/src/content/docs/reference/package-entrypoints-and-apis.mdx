## Entrypoints

### `@opsydyn/crumbs-css`

Use the package root for:

- `NativeStylesDiagnosticCode`
- `withNativeStyles`

### `@opsydyn/crumbs-css/style`

Use this entrypoint in `.css.ts` authoring modules for:

- `style`
- `styleVariants`
- `recipe`
- `createThemeContract`
- `createTheme`
- `viewStyle`
- `textStyle`
- `imageStyle`
- type exports such as `NativeRecipeProps`

### `@opsydyn/crumbs-css/theme`

Use this compatibility entrypoint in runtime/component code when you need the
advanced theme APIs:

- `createThemeDependencyPlan`
- `createThemeDependencyResolver`
- `resolveRecipeStyle`
- `createRecipeResolver`
- `TokenThemeProvider`
- `TokenThemeScopeProvider`
- `useTokenTheme`

### `@opsydyn/crumbs-css/theme/core`

Use this lean entrypoint for common provider, hook and token-resolution code:

- `ThemeProvider`
- `useTheme`
- `useThemeSelector`
- `useThemedStyle`
- `useThemedStyles`
- `resolveThemeTokens`
- `resolveThemeStyles`
- `createThemeTokenReference`
- `isThemeTokenReference`

It is emitted as an independent graph so consumers that do not need scopes,
dependency plans or recipe controls do not load those implementations. Both
theme entrypoints retain a React-only external runtime dependency boundary.

`createRecipeResolver(recipe, { cacheSize })` precomputes the recipe selection
plan and returns a callable resolver with `getCacheStats()`, `clearCache()` and
`dispose()` controls. The cache is resolver-local, least-recently-used and
bounded to `0..1024` entries; the default is `32` and `0` disables retention.

`useThemeSelector(selector)` subscribes to the selected value of the nearest
theme snapshot. Selectors should return a stable reference for unchanged
input; primitives are the simplest choice. The hook is intended for focused
token or derived-style reads when a component should not observe unrelated
theme changes.

### `@opsydyn/crumbs-css/metro-plugin`

Use this entrypoint in `metro.config.js` for:

- `withNativeStyles`

### `@opsydyn/crumbs-css/dist/transformer`

Advanced/debugging surface for direct transformer access. Most consumers should not import this directly in app code.
