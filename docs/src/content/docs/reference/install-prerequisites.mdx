title: Install prerequisites
description: What consumers need in place before @opsydyn/crumbs-css can work.
---

## Required peer dependencies

- `react`
- `react-native`
- `metro`

Expo apps already satisfy the Metro side of this setup.

## Validated baseline

The current package contract is validated against:

- Expo SDK 56
- React 19.2
- React Native 0.85

## Required app setup

- Metro must be wrapped with `withNativeStyles`
- `.css.ts` authoring modules should import from `@opsydyn/crumbs-css/style`
- themed styles should be resolved before render

## Recommended environment

- Expo or React Native app using Metro
- clean Metro cache after configuration changes
- Storybook or Expo Dev Client for visual integration checks

## Known Expo Doctor caveat under Bun

If the consumer app is installed with Bun, `expo-doctor` can still report
duplicate Expo packages from Bun's `.bun/` symlink layout even when every
duplicate is the same version. Treat that warning as advisory until Expo Doctor
and Bun converge on the same install model.

## Current scope

This package is documented for React Native consumers first. Browser CSS runtime parity is out of scope.
