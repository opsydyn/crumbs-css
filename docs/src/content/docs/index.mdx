## v1 stable release

The v1 package includes standalone variables, container conditions, native motion,
colour/typography algebra and typed runtime extensions alongside the core styling APIs.
Install the verified `1.1.0` release for Expo SDK 56 / React Native 0.85 or Expo SDK 57 / React Native 0.86. It retains the complete v1 API and adds the qualified Expo 57 peer range.
Use the [package quickstart](/crumbs-css/tutorials/get-started/)
and [complete API index](/crumbs-css/reference/package-entrypoints-and-apis/#complete-public-api).

## Documentation map

This site follows the Diataxis model:

- **Tutorials** teach the package by building something real.
- **How-to guides** solve one task at a time.
- **Reference** defines the package contract and current guarantees.
- **Explanation** covers architecture and tradeoffs.
