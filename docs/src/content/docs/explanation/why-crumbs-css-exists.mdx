---
title: Why crumbs-css exists
description: Why this package exists instead of using browser CSS patterns directly in React Native.
---

`@opsydyn/crumbs-css` exists to bring a familiar vanilla-extract-shaped authoring model to React Native without pretending React Native is a browser.

That means:

- keep the authoring mental model familiar
- compile at Metro transform time
- stay explicit about native state and runtime constraints
- reject browser-only CSS features instead of emulating them poorly

The package is opinionated about where parity stops. It values a coherent React Native contract over browser-like surface area.
