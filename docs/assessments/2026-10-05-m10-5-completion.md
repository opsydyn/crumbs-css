# M10.5 consolidated qualification

Roadmap: **M10.5**. Scope: one approved implementation and qualification slice, one final commit. Android is included. All physical-device work is deferred by the user. Host performance qualification remains subject to the recorded results below; engineering checks do not activate failed or uncalibrated guarantees.

## Shipping changes

The native compiler captures configuration, authored-input, installation and logical/canonical resolution receipts. The existing Metro importer invalidation bridge and disk-cache wrapper reject changed receipts. Entry buffers must match saved bytes. Configuration discovery receives a verification pass; a warm unchanged graph compiles once. Concurrent edits are retried at most three times, then rejected. This bounds consistency checks; it is not an atomic filesystem snapshot.

Resolution hints retain only immutable authored import plans: at most 128 owners, 512 authored files, 1,024 imports and 64 KiB of characters per owner. Large graphs are verified in full and not retained as truncated hints. Sources, evaluated exports, outputs and esbuild contexts are not retained. No production compiler-context cache is selected. The public APIs and legacy cache metadata remain compatible.

Nearest package-identity changes require Metro restart. Configuration/dependency edits can refresh; installation receipt invalidation does not unload executable modules already held by Node. Loaded compiler/plugin replacement and process-owned loader changes still require restart. Package-config resolution follows current logical paths rather than Node's cached resolver. Independent review reproduced imported-workspace configuration, package-extends links, relative links, alias links and sequential edits after retargeting; the corrected receipts detected all five fresh-output-changing cases.

## Direct qualification

- Shipping Metro: cache-enabled watched Expo CLI; 17 edit/restoration rows, 16 successful bundles and one expected syntax-error control. Every successful bundle matched current entry bytes and a complete fresh shipping transform. Shipping inventory stayed unchanged. This is host correctness evidence for the iOS non-development bundle protocol, not Android bundle parity or performance.
- Packed consumer: independent installed artifacts, iOS/Android/web export inventories, runtime isolation, theme snapshot, compatibility/migration and second-brand journeys. Android inventories also have a missing-component-package negative control. Local packed qualification does not establish publication or physical/native execution.
- Native: iPhone 17/iOS 26.4 simulator and API 36 ARM Android emulator with Expo Go SDK 56. Light/dark and selected-action journeys, LTR/RTL preview and restoration, dynamic type/font scaling and increased contrast. Android additionally reports reduced motion from the installed React Native adapter's transition-animation setting. Spoken VoiceOver/TalkBack acceptance and iOS reduced-motion preference switching are not established by these checks.
- Fast Refresh: both running native instances showed a temporary authored CSS colour and restored it without a reload command. The source bytes were restored. Android's restored frame matched exactly. iOS reset the demo's local animation marker during refresh; the full edit/restore screenshot comparison is retained as failed, not silently excluded. The independent unchanged-frame repeatability comparison passed with zero differing RGB pixels in the fixed body ROI on both platforms. This is bounded visual repeatability, not exhaustive recipe coverage or local-animation state preservation.
- Worker lifecycle: graceful shutdown left no observed processes from the owned Metro tree, including its esbuild services. No explicit retained-context disposal or release-memory claim follows from process absence.

The package and Storybook regression, package/consumer typechecks, production build and docs build are recorded in the evidence summary. Host smoke failures and registry failures remain visible. No approved ceiling or baseline was raised.
