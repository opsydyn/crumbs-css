## Failure boundaries

**Alias retargeting.** The watched fresh CLI records `tsconfig.base.json` modification. Both normal and cache-disabled sequences reuse the preceding alias-added transform observation, and the unchanged importer remains stale. Direct independent fresh compilation resolves the new alias correctly. The generated Metro dependencies contain canonical resolved token/nested/workspace source imports, but no tsconfig dependency or authored alias identity. Metro's installed `Graph.traverseDependencies` admits modified paths already present in the graph. This supports a missing configuration-to-importer invalidation bridge; it is not an esbuild retained-context or Vanilla Extract evaluation failure. Entry invalidation/new-owner recovery is diagnostic, not an accepted user workaround or production implementation.

**Symlink retargeting.** The watcher reports the package link as a symlink change. Installed Metro explicitly requests a graph reset for symlink changes, but the cached sequence performs no new CSS worker invocation: its last observed transform is the preceding manifest-exports row. Installed `Transformer.transformFile` combines options/global identity with the entry SHA for cache lookup; the Crumbs dependency identity is produced only after compilation. Generated CSS dependencies use resolved canonical source imports, so the authored package/link identity is absent from that surface. Disabling disk transform cache under the same watched CLI sequence causes a new worker invocation, the new baked value and exact fresh receipt parity. This localises the observed failure to pre-transform cache invalidation, rather than retained esbuild state. The isolated stock owner already disables this cache, explaining its different result. A generic claim that all symlink resolution is broken would exceed the evidence.

**Workspace import and restored entry.** The older harness polls for native values, then reads the latest worker trace. Import spelling changes leave values unchanged; restored content may also be served from a valid transform cache. Those facts do not bind that trace to the returned bundle. The pilot shows mismatched current/supplied entry hashes while the requested values are present. The corrected private isolated collector waits for an observation of the current entry bytes and obtains exact parity. The old mismatches therefore cannot establish a compiler defect. Historical failed gates are retained; this slice does not retrospectively qualify the cached bundles or change shipping acceptance.
