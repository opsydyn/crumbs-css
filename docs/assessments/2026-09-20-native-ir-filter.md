# M2.2ax filter structured IR

The installed React Native 0.83 style contract defines `filter` on `ViewStyle`, which is inherited by `TextStyle` and is absent from `ImageStyle`. Its array union contains seven non-negative amount functions (`brightness`, `contrast`, `grayscale`, `invert`, `opacity`, `saturate`, `sepia`), `blur`, `hueRotate` and `dropShadow`. The processor accepts numeric and unit-bearing strings with different rules for each function; `dropShadow` has its own offset, standard-deviation and colour payload.

Crumbs now captures marked static filter arrays into the Effect-backed structured IR. Amount functions accept finite non-negative numbers or finite bare, percentage and pixel strings. Blur accepts finite non-negative numbers or finite bare/pixel strings. Hue rotation accepts zero and finite `deg`/`rad` strings. A drop shadow is a plain item with required finite numeric, zero or pixel `offsetX`/`offsetY`, optional non-negative finite numeric, zero or pixel `standardDeviation`, and optional finite numeric or non-empty colour string. Empty filter arrays remain valid whole-value replacements.

The capture boundary uses own-property descriptors and dense-array checks. It rejects accessors, symbol or non-enumerable decorations, sparse or subclassed arrays, extra keys, non-finite values, nested token references, animated nodes, unsupported units and image primitive domains without evaluating user getters. Effect Schema decoding repeats the closed function/item shape, provenance match and view/text primitive matrix. Lowering clones and deeply freezes function lists and nested drop-shadow items; composition keeps the last complete `filter` list.

Filter strings remain on the existing compatibility route. Static arrays with dynamic or malformed entries fail with `CRUMBS_CSS_UNSUPPORTED_STRUCTURED_VALUE` at the transformer boundary; callers should pass those values through React Native's runtime `style` prop. Experimental background arrays remain deferred because their gradient, size, position and repeat contracts need separate qualification. This slice changes no public package exports or native ABI and does not establish native-device rendering acceptance.
