## Stable contract and upgrading

Public APIs and published artifact formats now follow SemVer. Existing exports
and peer ranges are preserved. Stable removal requires a documented replacement,
migration guidance and at least one minor release of deprecation before removal
in a major release. This major version establishes the stable baseline; it does
not remove the earlier authoring/theme APIs.

Use the specific authoring/runtime/tooling entrypoint for the feature you need.
After installing a v1 package, restart Metro and regenerate compiled styles and
any manifests with the same installed compiler/runtime. Historical alpha tarballs
may lack delivered APIs despite sharing an alpha version. Applications do not
supply Effect as a peer or provide an Effect runner.

Validated consumer baseline: Expo SDK 56, React 19.2, React Native 0.85; Node >=22.0.0
for tooling. React/React Native/Metro peer ranges and Effect 4 pins are unchanged.

## Feature scope

- Native primitive composition, variants, typed component slots and finite atomic Sprinkles scales.
- Typed/scoped tokens, dependency-aware theme selection, codecs, optics and functional expressions.
- M11.1 standalone variables/local assignments; M11.2 named container conditions.
- M11.3 public Animated motion adapter; M11.4 colour and typography algebra.
- M11.5 typed runtime factories with explicit named imports and constrained argument snapshots.
- Manifest compatibility, policy, ownership, migration, DTCG import and style explanation tooling.
