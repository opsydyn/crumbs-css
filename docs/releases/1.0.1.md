# Crumbs CSS 1.0.1

M10.5 documentation correction: the v1.0.0 npm tarball retained a prepublication
README despite successful npm publication. This patch corrects that README and
the packaged compatibility notes, and updates current onboarding to 1.0.1.

Every runtime JavaScript and declaration file remains byte-identical to the
verified public v1.0.0 tarball. Exports, dependencies, peer ranges and all other
package metadata remain identical apart from the version. The original v1
[qualification and explicit disposition](1.0.0.md) remain unchanged. This patch
makes no new performance claim or future-release exception. Physical acceptance
remains deferred and M11.6 integrations remain parked.

only v1.0.1, checks the published v1.0.0 SHA-256, verifies product source identity,
and permits only exact checked-in README/compatibility bytes and the version
bump. A separate publisher downloads and independently verifies the sealed
185-file inventory before npm upload with provenance. Normal release workflows,
budgets, baselines and the immutable v1.0.0 tag remain unchanged.
