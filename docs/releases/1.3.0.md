# Crumbs CSS 1.3.0 — Native style inspector

Status: **release preparation in progress; npm publication pending**. The M9.3a implementation and native qualification are committed as `3a795b4` and `014f5c9`. The normal release workflow must qualify the final versioned source and publish its exact tarball before this record can claim registry availability.

## Included changes

- New opt-in `@opsydyn/crumbs-css/devtools/native` entry: `CrumbsDevtoolsProvider`, `CrumbsDevtoolsWidget` and `useCrumbsInspectorTarget`.
- Explicit target registration, scoped token/variant/override explanations, stale-capture indicators and on-demand Refresh.
- Safe preview/copy adapters with bounded retention; production-safe conditional integration keeps inspector implementation and metadata out of normal production bundles.
- Playground/Storybook dogfooding and a [guide with real iOS and Android screenshots](../src/content/docs/how-to/explain-native-styles.mdx).
- Native accessibility focus ignores missing node handles. Existing APIs and SDK56/57/58 peer ranges are retained.

## Qualification and limits

The [M9.3a closure packet](../evidence/2026-10-18-m9-3a-qualification-closure/README.md) records 11 Android replay receipts, retained iOS/web journeys and four native source cost runs. Closed updates make no explanation calls, inspector captures cause no target-parent rerenders, and registry targets/reports clear after unmount. Native development measurements are not release performance or heap-leak evidence.

The implementation passes 1,931 package tests (one existing opt-in Node-floor skip), 34 Storybook tests, qualification regressions, strict SDK58 native types, both worker app exports and packed Babel/Rust development/production graph checks. Those pre-version qualification artifacts do not substitute for the final release tarball.

The normal publish workflow requires a fresh Apple M4 Pro host report under the accepted [M10.5 baseline](../evidence/2026-10-18-m10-5-v12-rebaseline/README.md), exact-source SDK56/57/58 receipts and independently verified transfer to the npm publisher. No budget changes or prior version-specific exception is included in this release.

Physical devices, spoken screen readers, independent usability and release frame/heap benchmarks remain deferred. Automatic element picking, live editing and desktop transport are outside this feature.
