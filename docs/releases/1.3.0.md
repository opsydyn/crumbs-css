## Included changes

- New opt-in `@opsydyn/crumbs-css/devtools/native` entry: `CrumbsDevtoolsProvider`, `CrumbsDevtoolsWidget` and `useCrumbsInspectorTarget`.
- Explicit target registration, scoped token/variant/override explanations, stale-capture indicators and on-demand Refresh.
- Safe preview/copy adapters with bounded retention; production-safe conditional integration keeps inspector implementation and metadata out of normal production bundles.
- Playground/Storybook dogfooding and a [guide with real iOS and Android screenshots](../src/content/docs/how-to/explain-native-styles.mdx).
- Retained SDK56/57 qualification profiles pin Clipboard and safe-area dependencies exactly, preserving reproducible strict installation. A regression checks the actual profiles.
- Native accessibility focus ignores missing node handles. Existing APIs and SDK56/57/58 peer ranges are retained.
